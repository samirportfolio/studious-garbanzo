# WAHA WhatsApp Bot (different engine from Baileys)
WAHA Core (free, open source) running on Render free via Docker.
Dashboard: /dashboard - Start session "default", scan QR with WhatsApp Business app (Linked Devices -> Link a Device).
Bot brain: a separate bridge service will receive WAHA webhooks and reply using the same Bangla/English brain as the pairing bot.
Note: WAHA is unofficial (WhatsApp Web based), not Meta-endorsed - do not spam, replies only to incoming messages.
